Agent 共绘

开启后，AI Agent 可以直接在你当前打开的画布上作图 —— 画完即见、可撤销，不需要导出再导入。

默认关闭。不用它的话完全无感：不开就没有任何 AI 相关的界面，也不会有额外的网络行为。

怎么接

  1. 在 KaiBoard 里点右上角 ⚙ →「Agent 共绘」，把开关打开。
  2. 点面板上的 「复制配置给 Agent」。
  3. 把复制到的整段内容发给你正在用的 AI 助手 —— 它会写入 MCP 配置、安装配套 Skill。
  4. 重启你的 Agent 客户端（MCP 客户端要重启才会加载新配置）。
前提：你的 Agent 客户端要和 KaiBoard 页面在同一台机器上（都能访问 127.0.0.1:8787），并且 保持 KaiBoard 网页开着、「Agent 共绘」处于开启状态 —— 中继只在该页面会话期间运行。

换了令牌怎么办

点过「更新令牌并重新复制」后，旧令牌立即失效。把新复制到的令牌发给你原来的 Agent 即可，其余不用重装。

数据会离开我的电脑吗

不会。中继只监听本机 127.0.0.1，画布数据不向任何外部服务器发送；授权完全由你「把令牌显式交给 Agent」建立。关掉开关即断开。

连不上怎么排查

待补：三步诊断（中继是否在跑 / 页面是否接入 / 端口状态）与常见现象。

想让 Agent 画得更好

除了 MCP 本身，还有一个可选的官方 Skill，里面写了画图方法论与落板纪律。接入指令里已带上安装步骤。

存储与备份

  • 默认：数据存在浏览器本地数据库（IndexedDB）—— 无账号、不上传。
  • 可选：把存储位置指向一个本地文件夹，画板会落成真实文件（需 Chrome / Edge）。
  • 换机：顶栏「导出全部（备份）」→ 在新机器上「导入备份（合并）」。
  • 导入备份是平行合并：不会覆盖、也不会清空目标机已有的内容。
